#  Movie Recommendation System

##  Overview
- Developed a Content-Based Movie Recommendation System.
- Recommends movies based on content similarity instead of user ratings.
- Uses movie metadata such as genres, cast, crew, keywords, and plot overview.

##  Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Jupyter Notebook

##  Features
- Data cleaning and preprocessing.
- Feature engineering using movie metadata.
- Text vectorization with CountVectorizer.
- Similarity calculation using Cosine Similarity.
- Generates top movie recommendations based on user input.

##  Dataset
- TMDB 5000 Movies Dataset
- TMDB 5000 Credits Dataset

##  Workflow
1. Load and merge datasets.
2. Clean and preprocess data.
3. Extract relevant features.
4. Create tags by combining movie attributes.
5. Convert text data into vectors.
6. Compute cosine similarity matrix.
7. Recommend similar movies.

##  Outcome
- Provides personalized movie recommendations.
- Demonstrates NLP, feature engineering, and recommendation system concepts.

##  Future Improvements
- Add poster images and movie details.
- Deploy as a web application.
- Integrate collaborative filtering techniques.
